# BUG-036: Rehearsal Hall listeners do not look at the slides and the anti-fabrication guard is bypassed

- **Reporter**: User ("các agent có thực sự xem slides không? … khả năng cao agent đang bịa kết quả") + AI (measured on run-3)
- **Assignee**: AI
- **Branch**: from-3.12.2

## Summary
Run-3 of the Rehearsal Hall (3.22.2, 16 listeners, `viepilot-team-intro` v1) looked clean — 0 dropped reactions —
but the measurement says the clean result proves nothing:

- **Slides not seen:** the listener prompt only lists the paths of `qa/slide-N.jpg` ("Slide images (when listed)
  show exactly what is on screen: …"); nothing requires opening them and nothing checks it. Transcripts: 3/16 agents
  read any image (#13 all 8, #3 2, #25 2); 13/16 judged the deck from the spoken notes only.
- **Quote guard bypassed:** `parseListener` keeps a negative reaction when `line` is a substring of the segment. 15/16
  agents copied the *whole* segment text into `line` for all 85 states (scripted), so every check passes trivially.
- **Numbers not labelled:** attention / comprehension / emotion are per-segment model estimates written by the agent
  (often hand-typed tables in a helper script), but the report presents them like measurements.
- **3D hall:** the stage screen shows the slide heading text, not the slide image.
- **Run-over-run deltas null:** `aggregate({ previous })` reads `previous.summary`, but `data.json` stores it at
  `aggregate.summary`, so passing the previous run's data.json (as the workflow says) gives `deltas: null`.
- **Old sessions:** sessions created before the 3.22.2 fix keep `session.currentVersion: null` after migration
  (`setCurrentVersion` was called before the sync existed; migration does not backfill from proposal.json).

## Expected
- Every listener must view every slide image before listening (Claude Code: Read each `qa/slide-N.jpg`), report
  `slidesSeen: [1..N]` and one visual note per slide; the orchestrator verifies against the subagent transcript /
  tool-use record when available and marks the listener `visual: unverified` otherwise. Without images (no Deck QA
  renders) the report says "text-only rehearsal".
- `line` is required only for negative reactions and must be a selective quote (e.g. ≤ 60% of the segment, or ≤ 20
  words), never the whole segment for every state; a listener whose quotes are mechanical is flagged
  (`quoteQuality: mechanical`) and its negative reactions without a selective quote are dropped.
- Report and summary label the per-segment metrics as "model estimates"; summary shows visual coverage
  (listeners who saw the slides / total) and quote quality.
- The 3D (and 2D) hall screen shows the slide image when available.
- `aggregate` accepts either a previous aggregate or a previous `data.json`.
- Session migration backfills `currentVersion` from `proposal.json`.

## Acceptance Criteria
- [ ] Listener prompt requires viewing all slide images and reporting `slidesSeen` + per-slide visual notes
- [ ] `parseListener` rejects full-segment copies as quotes; flags mechanical quoting; counts it in `dropped`
- [ ] Visual coverage + quote quality in aggregate summary, report and summary.md; "model estimate" labels
- [ ] Hall replay shows slide images (embedded) when present; 2D fallback too
- [ ] `aggregate({ previous: dataJson })` gives deltas
- [ ] Old sessions get `currentVersion` backfilled
- [ ] Tests for each; full suite green
- [ ] Rehearsal run-4 on `viepilot-team-intro` v1 with the fixed version, compared with run-3
