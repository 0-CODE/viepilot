# Task 165.3 — ENH-117a: Spoken speaker notes + script deliverables (5/15/30 min)

## Objective
Every slide always ships with a script. Notes inside the .pptx are full spoken words in spoken style;
a separate script file adds timing, transitions and Q&A in three durations.

## Paths
- `lib/proposal-script.cjs` (new)
- `workflows/proposal.md`

## Implementation Notes
**Spoken-notes rules (user decision 2026-11-07):**
- Full words the presenter says — not keywords, not an essay.
- Spoken style: short sentences, one idea per line, line break at breath points, contractions/natural
  particles allowed ("nhé", "đúng không", "you know what").
- Numbers stay as digits and symbols: `96%`, `3x`, `$50K`, `2026`. Never "chín mươi sáu phần trăm",
  "ninety-six percent".
- Optional stage cues in brackets: `[dừng]`, `[nhấn]`, `[click]` (aligned with Phase 166 builds).

`lib/proposal-script.cjs` exports:
- `SPOKEN_NOTES_RULES` — the rules above as a string for prompt injection.
- `validateSpeakerNotes(slides, lang)` → `{ ok, issues: [{ slideIndex, code, detail }] }` with codes:
  `missing` (empty notes), `spelled-number` (regex for spelled-out numbers next to "phần trăm"/"percent"
  or common number words vi/en), `essay` (any line > 40 words), `cliche` (via `detectCliches`).
- `DURATIONS = [5, 15, 30]` and `planDuration(slides, minutes)` → per slide `{ include, seconds }`;
  shorter versions drop slides flagged `optional` and shrink time proportionally; cover + closing
  always included.
- `buildScriptMarkdown(manifest, { minutes })` → markdown with: header (title, duration, audience,
  voice), per slide `### Slide N — heading (mm:ss)`, spoken text, transition line, then
  `## Câu hỏi dự kiến / Expected Q&A` (≥ 3 hard questions + answers from manifest `qa`).

Workflow additions:
- Manifest gains `qa[]` (hard questions + answers) and per slide `optional` flag.
- pptx step: call `slide.addNotes(speakerNotes)` for **every** slide; run `validateSpeakerNotes`
  before writing; on issues → regenerate the affected notes once, then report remaining issues.
- New Script step writes `docs/proposals/{slug}-{date}-script.md` (default = chosen `--duration`,
  else 15) plus `-script-5min.md` and `-script-30min.md`, and `-script.docx` (same content via `docx`).
- md step: replace `> Speaker notes:` line with a link to the script file.
- Confirm banner lists script files.
