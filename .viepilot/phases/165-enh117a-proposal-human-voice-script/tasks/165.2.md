# Task 165.2 — ENH-117a: Restructure proposal workflow — Voice Profile, Story Brief, new content rules

## Objective
Rewrite `workflows/proposal.md` so steps run in order and the AI prompt produces human output.

## Paths
- `workflows/proposal.md`

## Implementation Notes
1. **Renumber steps sequentially**: Initialize → Context → Type → Language → Voice Profile →
   Story Brief → Quality Brief → Manifest → Docx content → Script → Visuals → Templates → pptx →
   Animation hook placeholder (filled by Phase 166) → docx → md → Review hook placeholder
   (filled by Phase 167) → Slides upload → Confirm. Bump workflow `**Version:**` to 0.2.0.
2. **Voice Profile step** — AUQ (Claude Code) / numbered text fallback; options from `VOICE_LEVELS`
   (1 Khiêm tốn, 2 Cân bằng, 3 Tự hào, 4 Founder story); `--voice <1-4>` skips the prompt. Store
   `manifest.voice = { level, id }`. Asked every run (user decision ENH-117).
3. **Story Brief step** — AUQ, each question skippable: why you built it, hardest moment, proudest
   moment, one real customer/user story, the number to remember, the sentence you want repeated.
   Store `manifest.story`. Empty answers → no fabrication; `[cần chất liệu thật]` marker.
4. **AI Prompt Contract** — replace the old `CONTENT RULES` block with: `loadPromptContract()` text +
   `buildVoiceInstruction(level, lang)` + `{langInstruction}` + story material. Remove the
   "We believe" ban and the "8–15 words / action verb" rule. TONE line derived from voice level +
   decision-maker, not binary.
5. **Narrative arc mapping** — for each of the 4 types, annotate each skeleton slide with its arc beat
   (context/conflict/turning point/solution/proof/invitation). Skeleton remains the minimum set (ENH-045).
6. **Manifest schema** — add `voice`, `story`, and per slide `speakerNotes` = full spoken words in
   spoken style (see 165.3 rules) and `durationSec` estimate.
7. Keep ENH-039 lang, ENH-044 visuals, ENH-045 dynamic slides and designConfig sections intact.
