# Task 165.1 — ENH-117a: Prompt contract + voice & cliché helpers

## Objective
Move the proposal AI prompt rules into a testable template and add helpers for the Voice Profile and
an AI-cliché blacklist, so the workflow (165.2) and the persona review (Phase 167) share one source.

## Paths
- `templates/proposal/prompt-contract.md` (new)
- `lib/proposal-generator.cjs`

## Implementation Notes
`templates/proposal/prompt-contract.md` — sections with stable headings:
- `## Voice` — maker's first-person voice ("tôi"/"chúng tôi", "I"/"we") is allowed and expected.
  Every claim of pride must carry evidence (number, customer, demo). No unbacked absolutes
  ("tốt nhất", "đột phá", "revolutionary", "best-in-class").
- `## Rhythm` — mix short and long sentences; never more than 2 consecutive bullets with the same
  grammatical shape; a slide may carry a single big sentence instead of bullets. Removes the
  "8–15 words, action verb" rule.
- `## Narrative arc` — context → conflict → turning point → solution → proof → invitation.
- `## Real material` — never invent anecdotes, customers or numbers; when Story Brief is empty write
  `[cần chất liệu thật]` / `[needs real material]`.
- `## Numbers` — keep digits and symbols (`96%`, `3x`, `$50K`); never spell numbers out in words.
- `## Banned clichés` — the blacklist, rendered from the module constant.

`lib/proposal-generator.cjs` — add and export:
- `VOICE_LEVELS` — array of 4 `{ level, id, label_vi, label_en, instruction }`:
  1 humble, 2 balanced, 3 proud, 4 founder-story.
- `buildVoiceInstruction(level, lang)` — returns the instruction for the level (default 2 when
  invalid), always appending the evidence-for-pride rule.
- `AI_CLICHE_BLACKLIST` — `{ vi: [...], en: [...] }`, ≥ 12 entries each. Seed:
  vi: "Trong thời đại số", "Không chỉ… mà còn", "Hãy cùng khám phá", "giải pháp toàn diện",
  "nâng tầm", "đột phá", "tối ưu hoá trải nghiệm", "hệ sinh thái", "trong bối cảnh hiện nay",
  "đóng vai trò quan trọng", "mang lại giá trị", "không ngừng nỗ lực";
  en: "In today's fast-paced world", "leverage", "seamless", "unlock the power", "cutting-edge",
  "game-changer", "revolutionize", "synergy", "best-in-class", "delve", "in conclusion",
  "it is important to note".
- `detectCliches(text, lang?)` — case-insensitive scan (both lists when lang omitted); returns
  `[{ phrase, index }]`.
- `loadPromptContract()` — reads the template file, returns its text.

Keep the existing exports unchanged.
