# Task 178.1 — ENH-128: Panel selection + message protocol + caps (lib)

## Objective
Pure functions to pick the panel and validate a debate transcript.

## Paths
- `lib/proposal-panel.cjs` (new)

## Implementation Notes
- `selectPanel(agg, listeners, { size = 5 })`: most negative primary persona, lowest attention, most unanswered objections, #20, one decision-maker (leadership/manager role); dedupe, size 4–6.
- `PANEL_LIMITS` (rounds 3, messages per agent per round 1–2, words per message 80) and `validateMessage(msg, { round, roster, sources })`: from/to in roster or "presenter"/"all", round order, word cap, R2 messages must reference another panelist (to ≠ presenter or quote another panelist), presenter messages must cite slide/notes/backstage/contentMap ids or say no-answer.
- `buildTranscript(messages)` → ordered, validated, with flags; `beforeAfter(listener, finalPosition)`; `unansweredQuestions(transcript)`.
