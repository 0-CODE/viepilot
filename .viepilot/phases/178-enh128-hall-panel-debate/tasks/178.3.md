## Implementation Notes
- `--panel off|relay|teams` (default relay when the hall runs). Relay: orchestrator spawns presenter + panelists as subagents and continues them with SendMessage each round, passing the round's messages; text-only hosts run rounds in-thread.
- Teams (Claude Code, `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1`, consent via AskUserQuestion): lead creates the team (presenter + panel), posts each round as tasks, teammates message each other directly; lead closes the round after every panelist posted (TeammateIdle can keep a teammate working); same protocol, transcript collected from messages.
- Gates (AUQ): panel input (members, engine, rounds) and output (headline: questions asked, unanswered, minds changed).
