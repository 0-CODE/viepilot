## Implementation Notes
- Prompts state the counting rule: "words = space-separated tokens (Vietnamese syllables count one each); count before you send" — same rule as `validateMessage` (export `countWords`).
- workflows/proposal.md Step 10c: an over-limit message goes back to its author once for a rewrite before merging; only a second failure is kept and flagged.
- Presenter: prompt rule "say a gap once, in varied words; never end every answer with the same phrase"; `repeatedPhrases(answers, {minWords:2, share:1/3})` flags a phrase (3–5 word n-gram) that appears in more than ⅓ of presenter answers; shown in the report panel section.
- Read token: each round prompt carries `readToken` (short nonce per round+persona, e.g. from `roundToken(round, persona, seed)`) that the panelist must echo as `token` in every message; `buildTranscript` flags a missing/wrong token ('round prompt not read'); workflow tells the lead to check it.
