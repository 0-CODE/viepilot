# Task 173.3 — ENH-122 + ENH-123: detectProcessLeak + detectDevNotes

## Objective
Bilingual detectors for changelog-style content and dev notes, with variant allowances and materiality.

## Paths
- `lib/proposal-curation.cjs` (new)

## Implementation Notes
- `detectProcessLeak(manifest, {type, variant, audienceProfile})`: versions, phase/task/request ids, commit hashes, file paths/function names for non-technical audiences, changelog verbs at bullet start (vi + en), dated chronological lists; allowances for progress/leadership reports (milestones as results vs plan) and tech-architecture (component names).
- `detectDevNotes(manifest, script, {lang})`: not-done / pending / remaining / watch-out / hedge phrases (vi accented + unaccented, en), whole-word; returns `{slide, location, quote, kind, materialHint}`.
- `enforceMaterialRule(findings, {type, variant})`: material items for decision audiences only allow fix|reframe.
