# Task 168.2 — ENH-118: lib/todo-mirror.cjs + `vp-tools todo`

## Objective
Deterministic core of the mirror: derive the todo list from PHASE-STATE, emit payloads for native
tools, maintain the fallback checklist, and detect drift.

## Paths
- `lib/todo-mirror.cjs` (new)
- `bin/vp-tools.cjs`

## Implementation Notes
`lib/todo-mirror.cjs` exports:
- `readPhase(projectRoot, phase)` → `{ dir, tasks: [{ id, title, status, file }] }` from the
  PHASE-STATE task table + `tasks/*.md` (title = first `# ` heading after "Task N.M — ").
- `buildTodoItems(phaseData, { steps = true })` → items `{ key, subject, activeForm, status,
  blockedBy }`. `subject` = `[vp] 168.2 — <title>`. When `steps` is true, also emit per-task gate
  items for the active task: `state in_progress`, `implement`, `verify`, `state done + push`.
  Map statuses: pending/not_started → `pending`, in_progress → `in_progress`, done/✅/skipped → `completed`.
- `toPayload(items, adapterTodo)` → JSON for the host tool: claude TaskCreate list
  (`subject`, `activeForm`, `addBlockedBy`), legacy TodoWrite (`todos[]: id, content, status`),
  `write_todos` full list (`description`, `status`).
- `renderChecklist(items)` / `writeChecklist(statePath, items)` → idempotent `## Todo` section in
  PHASE-STATE.md (`- [x] [vp] 168.1 — …`), replacing only that section.
- `checkPhase(projectRoot, phase, { phaseComplete })` → `{ ok, issues[] }`, issue codes:
  `task-file-without-row`, `row-without-task-file`, `checklist-missing`, `checklist-drift`
  (checklist status ≠ PHASE-STATE status), `incomplete-at-phase-complete`, `multiple-in-progress`.

`bin/vp-tools.cjs` command `todo` with subcommands:
- `todo list --phase N [--json]` — print items.
- `todo payload --phase N --adapter <id>` — print JSON payload for the native tool.
- `todo sync --phase N` — write/refresh the `## Todo` checklist.
- `todo check --phase N [--phase-complete]` — print issues; exit 1 when any issue.
Add to the help text.

## Acceptance Criteria
- [ ] items for a phase dir match its task files 1:1 with `[vp]` prefix and dependency `blockedBy`
- [ ] payloads valid for claude-code (TaskCreate), legacy TodoWrite and antigravity (write_todos)
- [ ] `todo sync` is idempotent (running twice → identical file)
- [ ] `todo check` exits 1 on each issue code; exits 0 on a consistent phase
- [ ] `--phase-complete` fails while any task is not completed
- [ ] `npm test` green
