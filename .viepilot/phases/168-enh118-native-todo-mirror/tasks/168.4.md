# Task 168.4 — ENH-118: `vp-tools todo enable` (consent-gated)

## Objective
Give users one safe command to turn on Claude Code's todo tools, which are opt-in on newer models.

## Paths
- `bin/vp-tools.cjs`
- `lib/viepilot-install.cjs`

## Implementation Notes
- `vp-tools todo enable --adapter claude-code [--yes] [--dry-run] [--project]`:
  - target `~/.claude/settings.json` (or `.claude/settings.json` with `--project`), reuse the
    read/merge/write approach of `hooks install`.
  - set `env.CLAUDE_CODE_ENABLE_TODO_TOOLS = "1"`; keep every other key; create file if missing.
  - without `--yes`: print the exact diff and ask y/N on TTY; non-TTY without `--yes` → print the
    command to run and exit 0 without writing.
  - `--dry-run` prints the diff only. Idempotent: already set → "already enabled", no write.
  - other adapters → print "no opt-in needed" or the adapter's `enable_hint`.
- Installer (claude-code target): print one hint line suggesting `vp-tools todo enable`. **Never
  write settings during install.**

## Acceptance Criteria
- [ ] `--dry-run` never writes; `--yes` writes the env key and preserves existing keys
- [ ] second run reports already enabled and leaves file byte-identical
- [ ] non-TTY without `--yes` does not write
- [ ] installer only prints a hint
- [ ] `npm test` green

## Verification
- `HOME=$(mktemp -d) node bin/vp-tools.cjs todo enable --adapter claude-code --dry-run` → exit 0, no file created
