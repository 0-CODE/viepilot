# Task 168.1 — ENH-118: Adapter todo capability (5 adapters, verified flags)

## Objective
Describe each host's native todo tool in `ADAPTER_CONTEXT` so workflows can detect and use it, and
record honestly which tool names are verified.

## Paths
- `lib/adapter-context.cjs`

## Implementation Notes
- Replace `todo_read` / `todo_write` keys with a `todo` object on every adapter (keep
  `tools.todo_read`/`tools.todo_write` as deprecated aliases derived from it so nothing breaks):
  ```js
  todo: {
    tools: ['TaskCreate', 'TaskUpdate', 'TaskList'],   // preferred, in detection order
    legacy: ['TodoWrite'],                              // fallback tool set
    mode: 'incremental',                                // 'incremental' | 'full-replace' | null
    statuses: ['pending', 'in_progress', 'completed'],
    single_in_progress: true,
    persists_across_compaction: false,
    subagents_share: true,
    verified: true,
    source: 'https://code.claude.com/docs/en/agent-sdk/todo-tracking.md',
    enable_hint: 'Set CLAUDE_CODE_ENABLE_TODO_TOOLS=1 in ~/.claude/settings.json env (vp-tools todo enable)',
  }
  ```
- antigravity: `tools: ['write_todos']`, `mode: 'full-replace'`, statuses incl. `cancelled`/`blocked`,
  `single_in_progress: true`, `verified: true`, source `https://geminicli.com/docs/tools/todos`.
- cursor-agent, codex, copilot: research the official docs (WebSearch/WebFetch) for the exact tool
  name — candidates: Cursor `todo_write`, Codex CLI `update_plan`, VS Code Copilot `todos`. Set
  `verified: true` **only** with an official doc/source URL; otherwise `verified: false`, keep the
  candidate name in `tools` and add `note`. Workflows treat `verified: false` as fallback.
- Export `getTodoCapability(adapterId)` → the `todo` object (or a `{ tools: [], mode: null, verified: false }` default).
- Update `lib/adapters/*.cjs` only if they duplicate tool maps (check first).

## Acceptance Criteria
- [ ] all 5 adapters have a `todo` object with `tools`, `mode`, `verified`, `source|note`
- [ ] claude-code prefers TaskCreate/TaskUpdate/TaskList and lists TodoWrite as legacy
- [ ] antigravity `mode: 'full-replace'`
- [ ] no adapter marked `verified: true` without a `source` URL
- [ ] `getTodoCapability` exported; old `tools.todo_write` still resolves (back-compat)
- [ ] `npm test` green
