# Task 168.3 — ENH-118: Mandatory gates in workflows, skills and tracker-agent

## Objective
Turn the mirror into enforced steps so agents cannot skip it.

## Paths
- `workflows/evolve.md`
- `workflows/autonomous.md`
- `workflows/resume-work.md`
- `skills/vp-evolve/SKILL.md`
- `skills/vp-auto/SKILL.md`
- `agents/claude-code/tracker-agent.md`

## Implementation Notes
Common block "Todo Mirror (ENH-118 — MANDATORY)" referenced by all three workflows:
1. Resolve `getTodoCapability(ADAPTER_ID)`.
2. Claude Code: `ToolSearch select:TaskCreate,TaskUpdate,TaskList` → else `select:TodoWrite` →
   else fallback and print `enable_hint` once. Other adapters: use `todo.tools` only when
   `verified: true`; else fallback.
3. Native: create items from `vp-tools todo payload --phase N --adapter <id>`; record returned task
   ids in-session. Fallback: `vp-tools todo sync --phase N`.
4. Always run `vp-tools todo sync --phase N` too (the checklist is the durable mirror for gates).

- **evolve.md**: after phase/task files are created → run the block for each new phase; the
  EVOLVE COMPLETE banner must show `Todo: ✓ {N} items ({native|fallback})`. Missing → evolve is not
  complete.
- **autonomous.md**:
  - Phase start: block above; **hard rule — no `vp-task-executor` dispatch before the todo list
    exists** (orchestrator check: `vp-tools todo check --phase N` exit 0).
  - Each state transition (task start / done) → `TaskUpdate` (or full-replace for `write_todos`)
    + `todo sync`; one `in_progress` at a time in sequential mode.
  - Task PASS and Phase Complete gates: add `vp-tools todo check --phase N` (and
    `--phase-complete` at phase end); FAIL → control point.
  - Remove the "Teams mode only" restriction on TaskCreate; Teams mode keeps its shared-list use.
  - After compaction / on resume → rebuild from PHASE-STATE (tasks don't persist).
- **resume-work.md**: rebuild the native list from PHASE-STATE at resume.
- **tracker-agent.md**: after every task-start/task-complete/phase-complete edit, run
  `node bin/vp-tools.cjs todo sync --phase N` and include `## Todo` changes in the same commit; report
  `todo check` result.
- **SKILL.md (vp-evolve, vp-auto)**: one short "Native todo mirror (ENH-118)" section pointing to the
  workflow block; list it in success criteria.
- Workflow and SKILL files must stay English-only (tests/unit/*enh031* forbids Vietnamese).
