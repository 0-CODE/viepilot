# Task 177.4 — BUG-036: Hall replay shows slide images

## Objective
The 3D stage screen (and 2D fallback) shows the actual slide image for the current slide.

## Paths
- `lib/proposal-sim-report.cjs`
- `templates/proposal/simulation/hall3d.js`

## Implementation Notes
- `writeRun(..., { slideImages: [path…] })` embeds each image as a data URI (JPEG, size cap ~400 KB each, skip if missing) in hallData.
- hall3d.js: screen texture from the image (THREE.TextureLoader on the data URI), heading text as fallback; 2D view shows the image above the seats.
