# Task 177.1 — BUG-036: Listener prompt: must view slides, selective quotes, slidesSeen + visualNotes

## Objective
The prompt makes viewing every slide a precondition and defines what a quote is.

## Paths
- `templates/proposal/simulation/listener-prompt.md`
- `workflows/proposal.md`

## Implementation Notes
- Before listening: open every image in {slide_images} (Claude Code: the Read tool on each path); output `slidesSeen: [n…]` and `visualNotes: [{slide, note}]` (what is on screen, one line each). No images listed → `slidesSeen: []` and the run is text-only.
- `line`: only for negative reactions (drop, low comprehension, negative emotion, objection) — the few words that caused it, never the whole segment; positive/neutral states leave it null.
- Workflow Step 10b: the orchestrator passes the image paths, and with Claude Code checks each listener transcript for Read calls on them (`verifyVisual`).
