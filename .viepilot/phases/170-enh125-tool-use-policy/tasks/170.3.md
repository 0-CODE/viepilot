# Task 170.3 — ENH-125: PreToolUse policy hook (consent-gated)

## Objective
Optional Claude Code hook that warns on or blocks Bash commands that edit/read/search files.

## Paths
- `lib/hooks/tool-policy-hook.cjs` (new)
- `bin/vp-tools.cjs`
- `lib/viepilot-config.cjs`

## Implementation Notes
- Hook reads the PreToolUse JSON from stdin; for tool `Bash` runs `classifyBashCommand`; `warn` → prints guidance (non-blocking exit), `block` → exit code that denies with the suggestion; `off` → no-op.
- `vp-tools hooks install --policy warn|block` registers it in settings via the existing hooks installer (consent prompt, `--yes`, `--dry-run`, idempotent, never duplicates entries); config key `tools.policy` (default `warn`).
- Shared installer flow will be reused by Phase 171 hooks.
