# Task 175.1 — BUG-034: deps_install step in the install plan

## Objective
Installed ViePilot copies get their production dependencies installed after every install / update.

## Paths
- `lib/viepilot-install.cjs`
- `bin/viepilot.cjs`

## Implementation Notes
- `buildInstallPlan`: next to the existing `package.json` copy (BUG-007, ~L213) also copy `package-lock.json` when it exists; after all copy steps for a viepilot dir push `{ kind: 'deps_install', dir: vpDir, useCi: <lock exists> }`; when `env.skipDeps` (from `VIEPILOT_SKIP_DEPS=1`) push `{ kind: 'note', text: 'Skipping dependency install (--skip-deps): run "npm ci --omit=dev" in <dir> later' }` instead.
- `applyInstallPlan(plan, { dryRun, runCommand })`: `deps_install` → command `npm ci --omit=dev --no-audit --no-fund` (or `npm install …` without lock); dry-run logs `[dry-run] deps_install <dir>: <command>`; real run calls `runCommand(cmd, args, { cwd })` (default: `child_process.spawnSync` with `stdio: 'inherit'`, `shell: process.platform === 'win32'`); non-zero exit or spawn error → push a warning log `deps_install failed in <dir> — run manually: cd "<dir>" && <command>` and continue (never `ok: false`).
- `formatPlan` / plan summary prints the new step.
- `bin/viepilot.cjs`: parse `--skip-deps` for `install` (help text), pass `VIEPILOT_SKIP_DEPS: '1'` through `runInstallViaNode`.

## Acceptance Criteria
- [ ] plan contains `deps_install` per installed viepilot dir and copies `package-lock.json`
- [ ] `--skip-deps` replaces the step with a note
- [ ] dry-run prints the exact command; real run uses the injected runner with `cwd` = installed dir
- [ ] runner failure → warning + manual command, install still `ok`

- `npm test`
