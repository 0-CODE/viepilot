# Task 176.7 — BUG-035: G8 AskUserQuestion for every question (all vp-* skills + Stop hook)

## Objective
On Claude Code, no ViePilot skill ends a turn with a plain-text question; the proposal run ends with an AUQ next step.

## Paths
- `templates/auq-policy.md` (new)
- `lib/tool-policy.cjs`
- `skills/*/SKILL.md`
- `workflows/proposal.md`
- `lib/hooks/auq-check-hook.cjs` (new)
- `lib/hooks-installer.cjs`
- `bin/vp-tools.cjs`

## Implementation Notes
- `templates/auq-policy.md`: every question to the user — gates, ad-hoc clarifications, the closing "what next" — uses AskUserQuestion on Claude Code (preload via ToolSearch); text fallback only on adapters without it; never end a turn with a question in prose.
- `vp-tools policy sync` also renders the AUQ block between `<!-- auq-policy:start -->`/`end` markers in every SKILL.md; `--check` covers it.
- proposal workflow: after `finishSession`, a closing AUQ (Iterate / Rehearse again / Log findings as a request / Done); also for the trial-style summary.
- Opt-in Stop hook: reads the transcript path from the hook payload, warns (non-blocking) when the last assistant message ends with "?" and that turn has no AskUserQuestion call; `hooks install --auq-check` with consent/--yes/--dry-run, idempotent; tests with temp HOME and fixture transcripts.

## Best Practices
- English only in workflows/ and skills/ (enh031 test).
- Tests resilient: `>=` for counts that may grow, no pinned version literals.
- Never touch the real `~/.claude/settings.json` in tests (temp HOME); hook/settings writes are consent-gated with `--dry-run`.
- Follow the ENH-125 tool policy once Phase 170 ships (Read/Grep/Edit/Write/Task/TodoWrite).
- Every new behaviour gets a regression test named after the BUG-035 group (e.g. `phase176-g1-...`).
- Keep existing session/store files readable: any schema change ships with a migration and a test on an old fixture.
