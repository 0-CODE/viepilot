# Task 176.5 — BUG-035: G6 curation, backstage, cross-file consistency, placeholder gate

## Objective
Fewer false dev-note hits, an honest localized backstage, and no contradictions or placeholders slipping into the package.

## Paths
- `lib/proposal-curation.cjs`
- `workflows/proposal.md`

## Implementation Notes
- `detectDevNotes`: require the dev-note sense (e.g. "đang làm" only with a work-item object / not after "mình"/"quên"); "chưa có" only with backlog nouns; quote the matched line, not the whole note; add a `keep` decision so a flagged line can be kept.
- `buildBackstage`: localized headings (vi/en), no duplicate of Q&A under Open items, Removed lists Content Map DROP items, Reframed lists only reframes whose new text is present on the slide or notes.
- `checkConsistency(manifest, files)`: flags the same fact stated differently (time words like trước/sau buổi, numbers, names) across slide text, notes and backstage.
- `findPlaceholders(manifest)`: `[...]` fill-in markers; Confirm Output must list them and require an explicit "ship with placeholders" choice.
