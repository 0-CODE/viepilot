## Objective
Rewrite workflows/proposal.md so every step has an input and/or output AskUserQuestion gate, plus detection of existing proposals, upgrade, iterate and resume.

## Paths

- `skills/vp-proposal/SKILL.md`

## Implementation Notes
- Gate inventory table at the top generated from/consistent with `GATES`.
- Step 0 Detect existing proposal: AUQ Upgrade / Revise / New / Keep; hand-edit warning with its three options; upgrade runs `upgradePlan` and writes `upgrade-report.md`.
- Every step: input gate (confirm source/choice; skip only with flag or `--yes`, stated) and/or output gate (accept / change / regenerate / stop); compute-only steps say `covered by gate: <step>`.
- `recordStep`/`recordDecision` after every step; outputs go to `versionPaths`.
- New Iterate step after Confirm Output: classify change request → invalidated gates → rerun only those.
- SKILL.md 0.5.0: `--resume [slug]`, re-entry rule for active sessions (Claude Code: invoke the skill again via the Skill tool), `--yes` records auto-accepted gates and never auto-accepts material-risk items.
