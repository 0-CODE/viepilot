# Task 171.3 — ENH-124 + ENH-126: Gate registry + upgrade plan

## Objective
Machine-readable list of workflow gates and a function that computes what an older proposal is missing.

## Paths
- `lib/proposal-gates.cjs` (new)

## Implementation Notes
- `GATES` (frozen): `{ step, kind: input|output, since: semver, changedIn?: semver[], askUser: true, coveredBy?: step }` for every workflow step (current 21 + new detect/iterate steps).
- `upgradePlan(provenance, installedVersion)` → `{ missing: [...], changed: [...], reuse: [...], newInputs: [...] }`; legacy provenance treats every gate after the base set as missing.
- `lintWorkflowGates(workflowText)` → steps lacking an AskUserQuestion gate or a valid `covered by gate: <step>` reference.

- Follow the ENH-125 tool policy once Phase 170 ships (Read/Grep/Edit/Write/Task/TodoWrite).
