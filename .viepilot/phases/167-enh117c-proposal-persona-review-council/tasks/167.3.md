## Paths

## Implementation Notes
Fill the Review hook placeholder from 165.2 with **Step: Persona Review Council**:
1. Optional AUQ: show selected personas (from `selectPersonas`) → accept / add / remove
   (#20 locked). `--review off|quick|full` (default quick; `off` still runs #20 only).
2. Spawn one subagent per persona **in parallel** (Claude Code `Agent` tool, general-purpose) with
   `persona-review-prompt.md` filled in. Text-only adapters: run personas sequentially in-thread and
   say so.
3. `parseReview` → `evaluateGate`. Pass → write report, continue.
4. Fail → `synthesizeFeedback` → rewrite **only** slides/notes/script under Improve; keep Keep slides
   verbatim; re-run steps for pptx/animation/script on changed slides; re-score. Max **2 rounds**.
5. Still failing after round 2 → AUQ with scoreboard + top issues; options: Accept current version /
   Run one more round / I'll give feedback directly / Provide more real material (→ Story Brief).
6. Always final AUQ: "Đọc thử slide {X} — nghe có giống bạn nói không?" (X = slide with lowest H1)
   with options Đúng giọng tôi / Cần tự hào hơn / Cần khiêm tốn hơn / Tôi sửa trực tiếp.
7. Write `docs/proposals/{slug}-{date}-review.md` via `buildReviewReport`; list it in Confirm banner.
SKILL.md: document `--review`, the council, the review report; add AUQ prompts to the skill's
"Prompts using AskUserQuestion" list.
