# Task 167.1 — ENH-117c: 20 persona library + selection + rubric gate

## Objective
Create the persona library and the deterministic logic that picks reviewers and decides pass/fail.

## Paths
- `templates/proposal/review-personas.md` (new)
- `lib/proposal-review.cjs` (new)

## Implementation Notes
`templates/proposal/review-personas.md` — one card per persona with fixed fields
(`id`, `name_vi`, `name_en`, `role`, `cares_about`, `loses_patience_when`, `will_ask`, `audiences`):
1 CEO/business owner with 3 minutes · 2 CFO / budget holder · 3 CTO / architect · 4 skeptical
engineering lead · 5 investor (angel/VC) · 6 procurement · 7 non-technical end user · 8 loyal existing
customer · 9 devil's advocate / competitor lens · 10 tech journalist · 11 legal & compliance ·
12 security expert · 13 designer / UX · 14 marketing / brand · 15 sales / channel partner ·
16 student / newcomer · 17 big-conference back row · 18 online/livestream viewer · 19 non-native
international partner · 20 **Biên tập viên Tính người** (humanity editor, `always: true`).
Plus a mapping table proposal type × audience → default persona ids, e.g.
product-pitch → 1,2,5,9,10,18,20; tech-architecture → 3,4,9,12,13,19,20; project-proposal →
1,2,6,7,11,15,20; general → 1,7,9,14,16,17,20. Plus the rubric table from SPEC.

`lib/proposal-review.cjs` exports:
- `loadPersonas()` → parses the template into 20 objects (throws on < 20 or duplicate ids).
- `selectPersonas({ type, audience, decisionMaker, mode = 'quick', add = [], remove = [] })` →
  quick: mapping defaults trimmed/padded to 6–8; full: all 20; off: only #20. #20 can never be removed.
- `RUBRIC` → 10 criteria `{ code, label, threshold, minAny? }` (H1 has `minAny: 3`) + `BLOCKERS`.
- `evaluateGate(reviews)` where `reviews = [{ personaId, scores: {H1..C8}, blockers: [] }]` →
  `{ pass, perCriterion: [{ code, avg, min, pass }], blockers: [...], failing: [codes] }`.

## Acceptance Criteria
- [ ] `loadPersonas().length === 20`, ids unique, exactly one `always: true` (#20)
- [ ] `selectPersonas` quick returns 6–8 ids including 20 for every type; full returns 20; off returns [20]
- [ ] `remove: [20]` still keeps 20
- [ ] `evaluateGate` fails when H1 avg ≥ 4 but one persona gives H1 = 2
- [ ] `evaluateGate` fails on any blocker even when all scores are 5
