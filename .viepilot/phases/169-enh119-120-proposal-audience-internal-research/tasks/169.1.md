# Task 169.1 — ENH-119: `internal-presentation` type + variants (shared variant framework)

## Objective
Register an internal presentation type whose variant decides slide skeleton, arc beats, diagrams,
default duration and suggested voice. Existing types behave exactly as before.

## Paths
- `lib/proposal-generator.cjs`
- `templates/proposal/pptx/` (only if a stock file is needed — prefer code fallback)

## Implementation Notes
- `PROPOSAL_TYPES['internal-presentation'] = { slides: 8, label: 'Internal Presentation', variants: true }`.
- `INTERNAL_VARIANTS` (frozen), each `{ id, label, slides, skeleton: [{title, beat}], diagrams,
  defaultDuration (one of DURATIONS from proposal-script.cjs), suggestedVoice (VOICE_LEVELS id), goal }`:
  - `team-intro` (8): Cover · Why we are here · The problem we saw · What we built/plan · How it works · What it means for your team · Timeline & who to ask · Q&A / how to get involved. Voice `balanced`, 15'.
  - `leadership-report` (8): Cover · Bottom line first (decision/status in one slide) · Where we are vs plan · Key numbers · Risks & blockers · Options & recommendation · Ask / decision needed · Appendix pointer. Voice `humble`, 5'.
  - `feature-demo` (7): Cover · The pain today · Live demo flow · Before/after · How to start using it · Known limits & roadmap · Feedback channel. Voice `proud`, 15'.
  - `training` (9): Cover · What you will be able to do · Concepts · Step-by-step 1 · Step-by-step 2 · Common mistakes · Practice / exercise · Cheatsheet · Where to get help. Voice `balanced`, 30'.
  - `all-hands` (8): Cover · Where we came from · Wins worth celebrating (credit people by name) · What we learned · What is next · How each team fits · Thank you · Q&A. Voice `founder-story`, 15'.
  Beats use the existing arc vocabulary (context, conflict, turning point, solution, proof, invitation).
- `validateVariant(type, variant)`: required only for `internal-presentation`; default `team-intro`
  when omitted; unknown variant throws listing valid ids; non-internal type with variant → throws.
- `getSkeleton(type, variant)` returns the skeleton array (internal from variants; existing types unchanged / undefined if not modelled in code).
- `getDiagramTypes('internal-presentation', variant)` → variant diagrams (leadership-report: `gantt`; feature-demo: `sequenceDiagram`, `flowchart`; training: `flowchart`; team-intro: `flowchart`; all-hands: `flowchart`). Existing signature for other types unchanged.
- `resolveTemplate`: when the type-specific stock file does not exist, fall back to `general.{ext}`
  (project override still wins). Existing types resolve to the same paths as before.
- Build the variant mechanism generically (`TYPE_VARIANTS[typeId]`) so 169.2 can add `research-proposal` variants without new plumbing; `INTERNAL_VARIANTS` = `TYPE_VARIANTS['internal-presentation']`.
- Export new symbols.
