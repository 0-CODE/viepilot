# Task 169.3 — ENH-119/120: Audience profile, free-text purpose hints + type recommendation

## Objective
Turn the four intake answers into a normalized `audienceProfile` and a deterministic recommendation
(type + variant + one-line reason + 1–2 alternatives), plus voice and duration suggestions.

## Paths
- `lib/proposal-audience.cjs` (new)
- `templates/proposal/purpose-consult-prompt.md` (new)

## Implementation Notes
- Zero dependencies; pure functions; bilingual (vi/en) reasons via `lang` option.
- `AUDIENCE_ROLES` = leadership, engineering, product, sales, marketing, operations, hr, finance,
  legal, new-hires, all-staff, clients, partners, investors, scientific-council, funding-agency, researchers, students, industry-partners (each tagged `internal` | `external`).
- `GOALS` = approve, update, demo, train, inspire, sell, fund, kickoff, report-progress, defend, transfer.
- Role tag `research` for scientific-council, funding-agency, researchers, students; industry-partners tagged `external`.
- `FORMATS` = in-person, online, recorded, hybrid. `KNOWLEDGE` = novice, mixed, expert. `SIZE` = small (≤10), medium (11–50), large (>50).
- `normalizeAudienceProfile(raw)` → `{ roles: [{id, weight: 'primary'|'secondary'}], decisionMaker: {role, cares: ['cost'|'risk'|'speed'|'technical'|'people']}, knowledge, size, format, goal, internal: bool }`; accepts free-text role aliases (vi + en, e.g. "ban giám đốc"→leadership, "kỹ sư"→engineering, "nhân viên mới"→new-hires); unknown values kept under `other` and never throw.
- `internal` = every primary role is internal.
- `recommendProposalType(profile, {lang})` rules (ordered, documented in JSDoc):
  - external + goal fund/investors primary → product-pitch; external + engineering/partners technical → tech-architecture; external + clients approve/sell → project-proposal.
  - internal: goal approve or decision maker leadership → leadership-report; goal train or new-hires primary → training; goal demo → feature-demo; all-staff or size large + inspire/update → all-hands; else team-intro.
  - research: funding-agency primary or goal fund + research roles → grant-proposal; goal kickoff ("kickoff", "khởi động", "thuyết minh") → kickoff; goal report-progress or "nghiệm thu"/"tiến độ" → progress-report; goal defend or students/council + "luận văn"/"bảo vệ"/"hội thảo"/"conference" → defense; goal transfer or industry-partners + research roles → tech-transfer.
  - nothing matches → general.
  - returns `{ typeId, variant|null, reason, alternatives: [{typeId, variant, reason}] }` with 1–2 distinct alternatives, never the same as the pick.
- `suggestVoice(profile, rec)` → VOICE_LEVELS id (variant suggestedVoice, nudged to `humble` when decision maker cares about risk/cost).
- `suggestDuration(profile, rec)` → one of DURATIONS (variant default; leadership/large+online shortened one step).
- Free-text support (ENH-120), deterministic only:
  - `extractAudienceHints(text, {lang})` → partial raw profile (roles, goal, format, size, knowledge, decisionMaker) from vi + en keyword tables; returns `{ raw, matched: [{field, keyword}] }`.
  - `findIntakeGaps(profile)` → subset of `['roles','decisionMaker','knowledgeSize','formatGoal']` still unknown (drives which AUQ questions are asked).
- `templates/proposal/purpose-consult-prompt.md`: LLM contract for the consult with placeholders `{user_text}`, `{hints_json}`, `{gaps}`, `{recommendation_json}`, `{lang}`; output 5 sections: What I understood (3–5 lines) · Recommended type/variant + why + alternatives · Suggested outline & duration · Watch-outs for this audience · Still missing (only the computed gaps). Rules: do not invent facts; uncertain inferences flagged as assumptions; user's language.
- Export all constants and functions.

## Acceptance Criteria
- [ ] Each of the 5 internal variants, 5 research variants and the 4 external types is reachable from a realistic profile
- [ ] `extractAudienceHints` on a Vietnamese paragraph (e.g. kickoff đề tài cấp bộ, hội đồng khoa học) yields roles + goal; `findIntakeGaps` lists only unknown groups
- [ ] consult prompt template has all placeholders and the 5 sections
- [ ] alternatives length 1–2, distinct from the pick
- [ ] Vietnamese aliases map to role ids; unknown input does not throw
- [ ] `suggestVoice` / `suggestDuration` return valid ids
